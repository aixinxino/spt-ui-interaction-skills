# SPT · 项目交互设计总 Skill

这是一份统一入口的 Skill，整合 SPT 的 27 份 UI 与交互主题。你不用先记住各种动效名称，AI 会先看项目与当前任务，再选择有用的模式。它可以只选一处、组合几处，也可以判断现有界面已经足够，不添加动效。

## 不用安装，怎么使用？

1. 解压，保留 `spt-project-interaction-design` 文件夹的完整结构。它包含唯一的 `SKILL.md`、27 份主题参考和 3 份纸张交互细则。
2. 在能读取本地项目的编程 AI 中，将整个文件夹放到当前项目里你指定的普通资料目录，或把该目录提供给 AI。无需放进全局 Skills 目录，也不要只复制入口文件而漏掉参考资料。
3. 指明要处理的页面或功能，发送下面的请求。AI 会先读入口，再按需读取相关参考。

没有项目读取能力的聊天工具，需要你另外提供页面、截图、需求或代码。聊天工具能否直接读取 ZIP 取决于其能力；不能读取时先解压并上传入口及选中的参考。仅上传一张截图不能让 AI 完成真实项目集成。

## 直接复制：让 AI 判断并实现

> 请阅读附件或资料目录中的 spt-project-interaction-design/SKILL.md，并按需读取它链接的参考文档。这次需要处理【页面/功能】，我希望改善【问题或目标；不确定时请你先检查】。请先检查我的项目、现有组件和真实业务状态，选择确实合适的交互，简短说明位置和理由后直接实现。不要把全部效果塞进来，不要为了炫酷重做无关功能；现有组件已经够用的地方可以不改。保留当前设计风格与技术栈，完成后说明实际验证结果。不要安装这个 Skill，也不要自动发布或提交代码。

## 只想先看方案

> 请阅读 spt-project-interaction-design/SKILL.md，检查【页面/功能】，判断哪些地方值得加交互、哪些保持现状。给我具体位置、选用模式和简短理由。这次只做方案，不改代码，不安装任何东西。

## 已经知道要什么

> 请按 spt-project-interaction-design/SKILL.md 的路由，读取【例如：贴纸揭起、滑出取消、骨架屏】对应资料，在【位置】实现。其他效果不需要。保留现有组件与数据逻辑，检查取消、重复操作、手机适配和减少动态效果。
