# 6 种组件微交互

> 按需参考 · 主题 19《6种组件微交互》。仅使用总入口选定的模式，不把本页全部效果加入项目。任务范围、输出形式与语言以用户当前请求和总入口为准。

先检查目标组件、数据状态、输入方式和现有动画能力。只采用与用户任务有关的模式，沿用项目的视觉规范和技术栈。仅要求建议时不改代码；要求实现时完成真实操作，不只返回动画描述。

## 1. Multi-select Chips｜多选筛选标签

适合筛选条件或兴趣多选。按稳定 ID 保存选择集合，对勾、底色、宽度和计数都由同一集合派生。

选中时为对勾展开空间，标签真实变宽，邻项平滑让位；取消时反向恢复。测量实际换行，保持文字字号，不用横向缩放压扁文字。连续点击时最新状态生效，异步筛选忽略过期结果。

指令：做可多选标签，选中时展开对勾、加深底色，宽度变化带动邻项让位，计数同步；取消反向恢复，保留键盘选择与清晰的选中语义。

验收：计数始终等于集合大小；多行、长标签和快速反选不重叠或重复添加。

## 2. Removable Tags｜可删除标签

适合收件人、关键词等已选项。叉号是有可读名称的独立按钮，点击删除不要同时触发标签的选中动作。

删除时先呈现缩小淡出，再释放实际占位，让后续项目补位。按内容高度变化调整外框，不在每次删除时都缩一行。业务集合与短暂退场副本分开，动画回调不能再次删除另一条同索引记录。

指令：删除标签后短暂退场并释放占位，其余自然补位；仅当真实高度变化时调整输入框高度，保留正确焦点和一次删除的数据语义。

验收：连续删除、删除末项和撤销都按 ID 对应；焦点移动到邻项或输入框，不能消失。

## 3. Caret Suggestions｜光标联想

适合输入 @ 提及人物或选择实体。根据编辑器提供的光标范围定位候选，不能一直贴在输入框左上角。浮层靠边翻转或限高，滚动时跟随正确光标。

保存触发词范围；选择候选后替换该范围，插入带稳定实体 ID 的标签，将光标放在标签后继续输入。使用项目编辑器的文档操作接口，不直接拼入未经处理的 HTML。

处理方向键、高亮、回车与 Escape；中文输入法组字期间不抢确认键。远程查询需要隔离过期结果，空结果、失败和取消保留原文。

指令：输入 @ 后在光标附近显示人员候选，随关键词筛选；选择后插入对应实体标签并继续输入，处理中文输入、滚动定位和过期请求。

验收：段落中间插入、中文输入、换行、滚动和快速搜索均不会覆盖错误文本或失去光标。

## 4. Font-size Ruler｜横向字号刻度

适合编辑器字号调整。固定中央选中线，让数值刻度左右移动；明确合法范围、单位和步长，中心数值与实际字号一致。

拖动实时预览，松手吸附最近合法刻度；拖动偏移与数值双向映射，窗口变宽后重新测量。一次连续拖动形成一次撤销操作，而不是每一帧一条历史。提供键盘或数值输入替代。

指令：字号刻度横向跟手，中心值突出，两侧适度淡化，实时预览；松手吸附最近刻度，取消恢复，最终值与预览一致。

验收：最小最大值不会越界；慢拖、快速松手和反向操作选择准确；一次撤销恢复拖动前字号。

## 5. Touch-position Tilt｜触点倾斜卡片

适合可点击作品或功能入口。根据触点相对稳定卡片中心的位置计算受限倾斜，按左侧左边下沉、按右侧右边下沉；光斑与触点来自同一坐标。

用未被倾斜影响的基准边界测量，避免变换反过来改变坐标造成抖动。松手、移出或取消时复位。不要抢走页面滚动，也不要让倾斜范围使文字难读或点击区跑走。

指令：按压位置决定卡片轻微倾斜和光斑位置，限制幅度；松手或取消平稳复原，保持原有点击功能和手机滚动。

验收：四角方向正确，静止触点不抖动，移出取消不误点击；减少动态效果时保留普通按压反馈。

## 6. Recording Bar Morph｜按钮组展开录音条

适合聊天或语音记录。按实际平台检查麦克风权限与录音能力，仅在明确用户操作后请求。首次授权可能打断长按，需提供清晰的再次开始入口，不误显示已经在录。

状态为待机、请求权限、录音、取消预备、结束处理、试听或错误。长按后同一区域展开为录音条，计时和波形来自实际录音时长与音量；无分析能力时使用诚实的录音状态，不伪造实时波形。

持续捕获这一手势，上滑进入取消区域时改变提示和外观。正常松手结束后先试听，不自动发送；在取消区域松手丢弃本次录音并恢复按钮组。系统取消、失去捕获、切后台或卸载时按平台能力安全停止并清理麦克风资源。

指令：长按麦克风把按钮组展开为录音条，显示真实计时与音量；上滑可取消，正常松手进入试听，取消丢弃本次录音，权限拒绝和中断都有明确反馈。

验收：权限拒绝不伪装录音；滑入再滑出取消区结果明确；试听对应真实文件；取消后不上传、不发送且麦克风停止。

## 共用交付

保留文字、按钮和数据的真实组件语义。动态过程可被重复输入安全接续，到位停稳；减少动态效果时核心功能仍完整。验证目标页面的触摸、键盘、窄屏、长内容和失败状态，说明改动位置与实际验证范围，不凭截图声称交互已通过。
