# 5 种无限画布交互

> 按需参考 · 主题 15《5种无限画布交互》。仅使用总入口选定的模式，不把本页全部效果加入项目。任务范围、输出形式与语言以用户当前请求和总入口为准。

## 模式选择与实现约束

### 1. Pan & Zoom｜平移与缩放

适用：浏览大于视口的工作区域。

- 统一变换：屏幕局部坐标 s = world * zoom + pan，world = (s - pan) / zoom；先减容器视口偏移
- 指针锚定缩放：先求指针下的world，再令newPan = pointerLocal - world * newZoom，zoom夹取合法范围
- 空白拖动或空格拖动平移，节点拖动与框选有明确模式；双指缩放按平台能力实现
- 提供放大、缩小、复位及适应内容入口；主动拖动不附加慢速跟随

验收：光标下对象缩放时不漂，容器偏移、滚动与反复缩放后命中准确。

### 2. Marquee & Grouping｜框选与分组

适用：批量选择并组织画布对象。

- 框选矩形与节点边界统一到world坐标；明确相交还是包含
- 选择集合是暂态，持久分组是独立数据结构，不自动把框选当分组
- 移动选中集使用共同world增量保留相对位置；嵌套分组不重复移动子项
- 提供分组、解组、取消选择与撤销；输入框中不劫持编辑快捷键

验收：四方向框选、不同缩放、追加选择、分组后移动与解组都不丢对象。

### 3. Connector Binding｜连线绑定

适用：表达节点之间的关系。

- 边存储源目标节点ID及可选端口ID，端点由节点当前几何推导，不能保存为固定截图坐标
- 从锚点附近选择最短且可读的直线或正交路径；有障碍时绕行，优先少拐点，节点移动后同步更新
- 拖动预览、合法目标提示、释放提交分开；重连端点、删除边与删除节点是不同动作
- 是否允许自环、重复边、环路由业务决定；视觉连接不能被宣称为真实可执行数据流

验收：移动、缩放、调整节点尺寸后连线不断；取消连线不新增边，删除节点按规则处理关联边。

### 4. Auto Layout｜自动布局

适用：整理已经存在的节点与关系。

- 读取真实宽高、边关系与分组约束，选择树形、分层或网格；有向图不能盲用等距网格
- 明确整理选中对象还是全部，默认尊重用户范围、锁定节点和已有组
- 间距按节点尺寸计算，必要时路由连线；循环与孤立节点有确定布局规则
- 一次整理形成一个撤销事务；动画只展示最终坐标的变化，重复点击不启动互相争抢的布局

验收：长短卡片不重叠，孤立点不消失，局部整理不移动无关节点，撤销精确恢复。

### 5. Minimap Navigation｜小地图导航

适用：快速定位大画布中的当前视口。

- 内容包围盒由真实节点推导并留边距，与主画布共享同一个camera状态
- 视口world左上角为 -pan/zoom，宽高为viewportSize/zoom，再经小地图比例映射；不能手工播放假视口框
- 点击地图或拖动视口框反算world中心，再更新主camera；避免双向监听循环
- 空画布、远距离节点和窗口变化重算范围；提供适应全部且夹取合法缩放

验收：平移、缩放、拖动地图和增删节点后两处同步，反复导航无漂移。

## 状态与恢复边界

将文档状态（节点、边、组）、编辑状态（选区、工具、预览）和相机状态分开。预览不得反复写入远程存储；一次完成的拖动形成一次业务操作。提供项目所需的撤销、重做和保存失败反馈，不擅自添加协作或可执行工作流。

按本次选中且项目实际具备的能力，验证一条连续真实操作链。完整画布可参考：平移定位 → 指针缩放 → 框选多项 → 分组移动 → 新建或重连一条边 → 自动布局 → 小地图返回 → 撤销；删去不在任务范围内的步骤，不为补齐验收链新增功能。检查过程中从数据和页面同时确认所涉及的节点ID、边关系及选区未被动画重建。

## 动效与集成规则

- 拖动、滚动等连续输入直接控制当前进度；不要附加长时 CSS transition 让画面追赶手指。释放后的收尾才使用合适的缓入缓出或阻尼弹簧。固定动画时长根据距离、内容和设备调整，不把慢速当作顺滑。
- 点击反馈及时发生；短过渡可从约 160–280ms 起调，较大展开可从约 240–420ms 起调，这些仅是初值。稳定阅读时停住，不让整个页面持续放大或漂移。
- 一个属性同一时刻由一个控制源更新。重复输入从当前可见状态接续或明确合并，旧回调不能覆盖新状态。数据更新与装饰动画解耦。
- 测量真实内容尺寸，不用非等比缩放压扁文字、图片和控件。窄屏应改布局、换行或分页，长文本与空数据也能显示。
- 使用正确的原生元素或组件语义，保留键盘、触摸和辅助技术入口。减少动态效果时直接切换或使用短淡入，核心功能仍完整。
- 优先局部更新，避免每帧交错读取和写入整页布局；卸载时清理事件、定时器、动画循环与过期异步任务。

## 实际验收与交付

检查所选模式的正常操作、逆向或撤回、连续触发、取消、边界和内容变化。实际打开目标页面检查桌面与手机布局、键盘操作和减少动态效果；有构建或相关行为测试时执行适当检查。录屏或抽帧可用于发现遮挡、压缩和过渡跳变，但静态截图不能证明交互正常。

交付说明选型理由、修改位置、输入与结束规则、可调参数，以及实际执行的检查。区分结构检查、构建通过、浏览器操作和设备测试；没运行的验证明确标记，不承诺未经测量的性能。
