# 7种高级交互设计

> 按需参考 · 主题 11《7种跟手与手势交互》。仅使用总入口选定的模式，不把本页全部效果加入项目。任务范围、输出形式与语言以用户当前请求和总入口为准。

## 1. Interactive Back Gesture｜跟手返回

适用于有上一页或明确返回目标的详情页面。

- 从平台允许的起始区域识别返回手势，将有效轴上的位移映射为转场进度。拖动期间页面随手指更新，不启动与输入脱离的固定时长动画。
- 松手时结合当前进度、释放速度及方向决定完成或取消。轻微噪声不应翻转判断；阈值和速度权重根据页面尺寸与设备调节。
- 快速朝返回方向甩出可以完成未过半的转场；反向带回或进度不足且速度低时按规则恢复。不能写成所有向外甩动都必须返回。
- 收尾从当前可见进度接续，避免跳变。允许动画中途接管时使用第5种规则。
- 预览页面与真实路由提交分开。确认完成后只提交一次返回；取消后恢复当前页、焦点、可交互状态与必要的滚动位置。
- 协调系统边缘手势、嵌套滚动和已有原生返回能力，避免双重处理。无法安全接管原生导航时优先使用平台提供的交互式返回能力。
- 保留可点击和可键盘操作的返回入口；指针取消或手势丢失时回到确定状态。

验收：短距离快速甩出、长距离慢拖、中途停住、往回带和取消事件都有稳定结果；不存在重复返回或停留在半页的状态。

## 2. Press-slide Cancel｜按钮滑出取消

适用于提交、确认等按下后允许移出取消的按钮。

- 优先使用平台原生按钮的点击和取消语义，仅补充需要的视觉反馈；不要因自定义动画破坏原本正确的行为。
- 按下时进入按压态。按住并移动时，根据当前坐标与有效命中区域更新是否仍可触发，视觉压下程度可随离开距离平滑减弱。
- 在有效范围外释放不触发；再次移回后是否允许触发应与平台约定及用户需求一致，通常可恢复按压态，在内部释放触发一次。
- 命中范围基于稳定布局，可设置合理触摸容差；不要用正在缩放的外观反复改变命中判定。
- 指针捕获只保证后续事件送达，不代表指针仍在按钮内，需独立判断坐标。取消、失焦、禁用或开始滚动时清理按压状态。
- 避免指针释放回调与随后click事件重复执行业务。键盘、辅助技术及普通点击路径仍可用，禁用态不触发。

验收：内部释放、移出释放、移回释放、滚动取消、快速连点及键盘激活均符合预期；无卡住的按压态和重复提交。

## 3. Partial Text Transition｜文字局部过渡

适用于筛选摘要、月份、数量和短标题中的局部更新。

- 将稳定文案与变化字段按语义拆分，保留稳定节点身份，只对实际变化字段做过渡。不要每次更新都替换整行或整段容器。
- 月份等词组按字段切换，数字可按整体或数位滚动。选择能清楚表达变化的方式，不机械拆分所有中文字符。
- 处理数字位数、负号、小数、单位及不同文字宽度。可使用等宽数字或平滑调整局部宽度，不用固定宽度裁掉有效内容。
- 连续更新时合并过时目标或从当前可见状态接续，最终必须显示最新数据。不要让动画队列长期落后于真实值。
- 视觉用的旧值和新值副本不应被辅助技术重复读取；保留最新值的可访问文本，按信息重要性选择是否播报，避免高频逐帧播报。
- 减少动态效果时直接更新或短暂淡入，数据含义和可读性保持完整。

验收：未变文字保持稳定；长短文本、跨位数数字与快速更新无截断、错值或整行闪烁；结束状态与真实数据一致。

## 4. Gesture Axis Lock｜手势方向锁定

适用于横向翻图与纵向关闭等共用区域的操作。

- 起始阶段先累计位移，超过合理识别距离后，再依据横纵位移比例、方向优势等条件确定归属。接近对角线时可继续观察，不被第一个微小位移决定。
- 一旦识别为横向或纵向，本次手势保持锁定；后续轻微偏移不能同时触发另一行为。
- 结束或取消后清空锁定，下一次手势重新识别。点击未超过阈值时仍走点击路径。
- 在开始监听前按平台机制配置可交给系统的触摸行为，不能假设手势中途修改配置就能接回浏览器已占用的滚动。
- 明确嵌套滚动、边缘返回和多指输入的优先级；已有缩放手势时，不用单指方向锁定破坏双指缩放。
- 目标是减少误触，不承诺任何角度或设备都绝不误触。

验收：近水平、近垂直、对角线、轻微抖动、短点击和取消后重试均可用；同一次输入不会同时翻页并关闭。

## 5. Interruptible Motion｜动画中途接管

适用于惯性滑动、弹簧回位或自动归位中的可拖动物体。

- 用户再次按住运动中的元素时，读取其当前实际呈现的位置，并停止旧运动控制源。从该位置建立新拖动基准，保留手指与元素的相对偏移。
- 不把旧目标位置、起点或延迟的状态变量当作当前画面位置。若渲染位置由变换驱动，坐标换算要包含当前变换与容器滚动。
- 同一时刻只有一个控制源写入位置。取消旧动画的完成回调或使用版本标记，防止旧任务结束后覆盖新拖动。
- 接管后及时跟随手指；再次释放时依据新手势的速度计算后续运动，不无条件沿用旧惯性。
- 中断视觉运动不等于撤销已提交的删除、支付或导航。业务操作是否可撤销按原项目规则处理。
- 如元素飞出可交互范围或已完成移除，不虚构仍可被按住的行为；需要撤销时使用明确业务入口。

验收：在动画开始、中段、接近结束时按住均无跳跃；连续释放再接管不抖动；旧回调不会把元素拉走。

## 6. Predicted Snap Preview｜落点预览

适用于具有离散停靠位置的轮播、横向卡片或选择器。

- 根据当前滚动或拖动位置及平滑后的速度估计“此刻松手”的落点。使用实际卡片尺寸、间距、边界和允许跳过的项目数量。
- 将投影位置映射为合法吸附项，以标记、高亮或指示器展示预计目标。预览应能随用户减速、反向或继续拖动而改变。
- 预览和释放收尾调用同一套目标选择逻辑，使用一致的速度采样、边界处理和吸附点，避免预览一项却停到另一项。
- 预测跨过分界时可使用适度稳定策略，但不能让显示长期滞后。松手前预览是估计，不是对未来手势结果的锁定承诺。
- 不因预览就提交业务选择；按项目约定在释放或停稳时确认。不能控制平台原生惯性时，不伪造精确落点保证，应说明限制或选择可控方案。
- 收尾可包含轻微过冲回弹。回弹本身不代表算错，最终目标一致、过程可预期才是判断重点。
- 改变容器大小或数据列表后重算吸附点，失效目标需重新映射。

验收：快速甩动、慢速拖动、突然反向、首尾边界及不同宽度项目下，最终目标与释放时有效预测一致；不在拖动中错误提交选择。

## 7. Rubber-band Overscroll｜边界阻尼

适用于到达滚动边界后保留有限弹性位移的列表或面板。

- 区分真实滚动位置与视觉超出位移。真实位置限制在合法范围，越界部分使用有上限、增量逐渐变小的映射产生阻力感。
- 在边界处保持连续，避免从正常滚动突然跳到较大位移。越拉越难移动是视觉位移相对手指位移的变化，不是给输入处理加延迟。
- 松手后从当前超出量平滑回到边界。回弹尚未结束又被按住时，按第5种规则接管。
- 离开越界区重新进入正常范围时平滑衔接。短列表、底部边界、容器尺寸变化也要有明确行为。
- 优先使用平台原生弹性能力；若平台已经处理，不再叠加第二层回弹。与下拉刷新、嵌套滚动及系统边缘手势协调。
- 拉到边界不自动代表刷新或加载。只有已有明确需求时才加入这些业务触发及相应状态。

验收：上下边界均连续，长距离拉动不无限露底，松手能稳定回位；快速重复拉动无累积漂移，正常滚动和既有刷新功能不冲突。

## 平台适配与交付

先确认目标运行环境支持的输入、动画、导航和滚动能力。网页实现不能直接假定可在原生APP或所有小程序环境使用。优先利用可靠的原生机制，必要时再进行自定义。

装饰性缩放、滚动和回弹遵循减少动态效果偏好；保留完成任务的点击、键盘或可访问替代入口。非必要不依赖持续高频播报或悬停操作。组件卸载时清理事件、动画、指针状态和过期回调。

按所选交互验证正常输入、取消、中断、连续输入及边界。若目标设备可用，实际操作验证；只能检查代码时明确说明，不能把构建通过当作交互验收通过。

交付时说明选型理由、修改位置、完成与取消规则、主要可调参数及实际测试结果。未测过的设备或性能不作保证。参数根据具体界面调节，不把单个示例的阈值写成所有项目的固定标准。
