# 8 种展开类组件与交互

> 按需参考 · 主题 04《8种展开组件》。仅使用总入口选定的模式，不把本页全部效果加入项目。任务范围、输出形式与语言以用户当前请求和总入口为准。

## 模式选择与实现约束

### 1. Accordion｜手风琴

适用：多组可独立阅读的详情。

- 先确定单项或多项可展开规则
- 标题用按钮关联面板并设置展开状态
- 真实测量高度，异步内容变化重新测量

验收：快速切换无裁字，键盘能开合每一项。

### 2. Collapse｜折叠区域

适用：一个局部说明或高级设置区。

- 明确折叠后保留摘要还是完全隐藏
- 关闭时处理区域内部焦点，隐藏内容不可继续Tab进入
- 从当前高度反向收起，不能固定最大高度掩盖内容

验收：长内容与中途反向均连续，隐藏项不可误操作。

### 3. Tree View｜树形结构

适用：文件、组织或多层级项目。

- 节点稳定ID，展开、选中与勾选分别存储
- 左右键开合或进出层级，上下键移动可见节点
- 懒加载区分未加载、空节点和失败，展开可重试

验收：深层结构和异步节点正常，父级折叠不留下失焦。

### 4. Dropdown Expansion｜下拉展开

适用：锚点下方临时选项或操作。

- 面板沿触发器附近展开，空间不足翻转或滚动
- 保持文本原尺寸，裁切外壳或淡入内容而非挤扁整层
- 有关闭、外部点击和键盘退出路径

验收：边缘位置、快速开合及滚动定位正确。

### 5. Card Expansion｜卡片展开

适用：摘要进入同对象的更多详情。

- 保留对象ID和源位置，先确认就地展开还是进入覆盖层
- 就地展开让邻项平滑让位；覆盖层管理焦点与返回
- 图片保持比例，内容独立进入，不放大一张截图充当详情

验收：开合后回到同一对象，长文本和换行不溢出。

### 6. Sidebar Expansion｜侧栏展开

适用：图标侧栏显示文字与分组。

- 先决定推动正文还是覆盖正文，避免两者混合
- 图标基准和点击区稳定，文字在足够宽后揭示
- 小屏改抽屉，不把正文压成窄条

验收：反复切换无累积偏移，正文最小可读宽度得到保证。

### 7. Radial Menu｜径向菜单

适用：围绕工具中心的少量快捷操作。

- 按实际可用角度和半径布置按钮，边缘自动调整
- 先确认拖选还是点击选择，提供线性菜单替代
- 各按钮名称和键盘入口完整，不遮挡触发点

验收：四角打开不越界，取消不误执行，触摸可准确选择。

### 8. Container Transform｜容器转换

适用：同一对象从紧凑入口进入完整任务区。

- 源与目标保持可识别对应，记录位置尺寸圆角
- 外壳变化与内部排版分开，文字不能随非等比缩放变形
- 关闭回到有效源；源消失采用明确降级退场

验收：两个方向连续，换屏和源项删除后不会飞向旧坐标。

## 动效与集成规则

- 拖动、滚动等连续输入直接控制当前进度；不要附加长时 CSS transition 让画面追赶手指。释放后的收尾才使用合适的缓入缓出或阻尼弹簧。固定动画时长根据距离、内容和设备调整，不把慢速当作顺滑。
- 点击反馈及时发生；短过渡可从约 160–280ms 起调，较大展开可从约 240–420ms 起调，这些仅是初值。稳定阅读时停住，不让整个页面持续放大或漂移。
- 一个属性同一时刻由一个控制源更新。重复输入从当前可见状态接续或明确合并，旧回调不能覆盖新状态。数据更新与装饰动画解耦。
- 测量真实内容尺寸，不用非等比缩放压扁文字、图片和控件。窄屏应改布局、换行或分页，长文本与空数据也能显示。
- 使用正确的原生元素或组件语义，保留键盘、触摸和辅助技术入口。减少动态效果时直接切换或使用短淡入，核心功能仍完整。
- 优先局部更新，避免每帧交错读取和写入整页布局；卸载时清理事件、定时器、动画循环与过期异步任务。

## 实际验收与交付

检查所选模式的正常操作、逆向或撤回、连续触发、取消、边界和内容变化。实际打开目标页面检查桌面与手机布局、键盘操作和减少动态效果；有构建或相关行为测试时执行适当检查。录屏或抽帧可用于发现遮挡、压缩和过渡跳变，但静态截图不能证明交互正常。

交付说明选型理由、修改位置、输入与结束规则、可调参数，以及实际执行的检查。区分结构检查、构建通过、浏览器操作和设备测试；没运行的验证明确标记，不承诺未经测量的性能。
