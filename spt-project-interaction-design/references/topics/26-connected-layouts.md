# 连续布局交互

> 按需参考 · 主题 26《6种高级布局交互》。仅使用总入口选定的模式，不把本页全部效果加入项目。任务范围、输出形式与语言以用户当前请求和总入口为准。

先阅读项目现有页面、组件、状态管理和交互约定，判断用户想完成什么、哪里需要变化、哪里应该保持稳定。保留项目的视觉规范和已有组件；从下列模式中只选择有用的部分，不把六种效果全部塞进同一页。若用户仅要求建议，给出适用位置和理由，不直接改项目。

## 选择模式

| 场景 | 模式 | 应保持稳定的内容 |
|---|---|---|
| 大封面下有需要持续查看的摘要或进度 | 重叠吸顶 | 摘要卡身份、数字与阅读位置 |
| 表单选项直接影响页面标题或预览 | 标题联动 | 未变化文字、布局、焦点 |
| 需要同时查看背景并调节参数 | 非模态底部面板 | 背景仍能操作，预览不中断 |
| 在日历对应日期录入记录 | 日历原位补录 | 被编辑日期、已保存数据 |
| 多栏目共享一个高频新建操作 | 导航里的主操作 | 主按钮位置、各栏目滚动状态 |
| 仅切换页面头部内容，正文仍有用 | 封面局部翻页 | 下方列表、滚动位置 |

## 1. 重叠吸顶

让摘要卡与封面下沿重叠，同时为它占用的空间保留布局位置。滚动时封面自然退出，摘要卡到导航下沿后停止，正文继续滚动。优先使用平台的 sticky 能力，先查明实际滚动容器；检查祖先的 overflow、transform、容器高度和导航偏移，避免 sticky 无效或被裁切。不缩放文字来制造封面收起效果。

验收：慢滚、快速滚、反向滚动都连续；导航不遮挡卡片；正文不会在卡片吸顶时突然跳动。

## 2. 标题联动

选择器和标题绑定同一业务状态。只对变化的词或数值做替换动画，保留未变化文案。为变化文字留出足够宽高，使用裁切容器进行约 160–260ms 的局部位移和淡入；尺寸依据最长实际内容决定，不凭固定字数猜测。连续切换时取消或接续旧动画，最终状态必须与已选项一致。必要时用 aria-live 礼貌播报结果，避免逐动画帧播报。

验收：连续点击、中文长词和加载失败时无错位、重复文本或旧状态残留。

## 3. 非模态底部面板

优先使用现有的非模态 Sheet 或适配已有面板。无全屏拦截层，上方画面保持可点击、可滚动；不要给这种面板设置模态焦点陷阱或 aria-modal=true。提供明确收起按钮，并按平台惯例支持向下拖动收起。输入框、滑杆和内部滚动区的手势不能被关闭手势抢走；先判断拖拽起点和方向，再进行拖动。

是否点击外部关闭由场景决定；背景点击有自己的操作时不要同时触发关闭。修改未保存内容时保留草稿或明确处理取消，不无声丢失用户输入。键盘弹出时面板内表单仍可见。

验收：打开面板仍能切换上方预览；拖滑杆不关闭面板；关闭后焦点回到合理入口。

## 4. 日历原位补录

日期用真实本地日历日期作为键。区分未记录、选中、草稿、保存中、保存成功和保存失败。点空日期先标记选中，再打开对应日期的编辑面板；保存成功后更新该日期缩略图及统计数量。取消保持原记录和数量不变。防止重复提交，失败时保留输入并允许重试。已有记录应编辑而不是新增一份。

缩略图回到日历的动画只是反馈，不承担保存事务。保留按钮和日期的语义标签，让不依赖颜色的用户也能区分状态。

验收：跨月、月初空白、时区切换、取消与请求失败都不会把数据写入错误日期。

## 5. 导航里的主操作

导航项负责切换页面，主按钮负责创建内容，用独立语义和事件实现。选中背景可以平滑移动，图标文字与点击区域保持稳定；切换后保留各页必要的滚动状态。主按钮在不同栏目保持可识别位置。是否跳转到某一栏目由任务决定，不强制回首页。

底部导航考虑安全区域和软键盘；滚动区底部 padding 应覆盖浮动栏的实际高度。少量入口使用正常 tab 或导航结构，不挤入过多图标。仅图标主按钮需要可访问名称。

验收：各页最后一条内容可完整滚到栏上方；返回键、键盘导航和切页状态符合现有应用惯例。

## 6. 封面局部翻页

图片、标题、页码相关信息绑定同一条内容标识，在同一裁切容器内运动。横向手势只在封面区域启用，先用小范围方向判断与纵向滚动协调。拖动时位移跟手；松手综合距离与速度决定前进、后退或回到当前项。不要仅按某个固定像素阈值判断所有尺寸与设备。

下方正文列表和滚动位置保持。边界使用有限阻尼和轻提示，不出现空白页；快速反向拖动允许从当前可见位置接管。为无触摸输入提供前后切换按钮，预加载相邻图片避免闪白。降低动态效果设置下使用立即切换或短淡入。

验收：慢拖取消、快速甩动、连续反向操作、首尾边界、图片加载失败和纵向滚动都合理。
