# 7 种展开与形态变化动画

> 按需参考 · 主题 06《7种形态变化动画》。仅使用总入口选定的模式，不把本页全部效果加入项目。任务范围、输出形式与语言以用户当前请求和总入口为准。

## 模式选择与实现约束

### 1. Circle to Pill｜圆形变胶囊

适用：图标入口展开为带文字的按钮或状态。

- 以真实圆形直径和目标文本宽度计算终点
- 明确中心或边缘锚定，圆角维持胶囊半径
- 先留出文字空间再揭示文字，点击区不突然漂移

验收：长文案、快速开合和窄屏不溢出，仍是同一个操作。

### 2. Pill to Card｜胶囊变卡片

适用：简短状态进入详情卡片。

- 宽高分阶段或协调变化，按实际内容决定目标尺寸
- 圆角独立过渡，标题与正文按阅读顺序进入
- 卡片排版真实存在，不通过拉伸胶囊里的文字模拟

验收：正文清晰，逆向时内容先有序退出再收窄。

### 3. Compact to Expanded｜紧凑态展开

适用：播放器、搜索或局部控制区增加操作。

- 定义两态实际可用内容和功能，保留共享锚点
- 隐藏控件不获取焦点；新增控件出现后才可交互
- 保持已有输入、播放或选择状态

验收：展开不重启业务，连续点击最终状态与用户意图一致。

### 4. Corner Radius Morph｜圆角变化

适用：对象从柔和入口转为面板或全屏容器。

- 按起止尺寸控制圆角，避免超过有效几何范围
- 遮罩、图片裁切与背景同步，边框和阴影自然衔接
- 不要让内部文字或整页跟着圆角效果缩放

验收：各阶段不漏底，无突然方角或双重边框。

### 5. Size Morph｜尺寸变化

适用：内容增加或容器状态变化。

- 测量真实宽高，明确周围布局是否跟随让位
- 采用布局动画或测量过渡，临时缩放层需保护文本比例
- 图片加载、字体变化和窗口调整后重新计算

验收：变长变短无裁字，最终移除临时固定尺寸。

### 6. Content Reflow｜内容重排

适用：容器变宽或展开后排列方式改变。

- 保持项目稳定ID，用起止布局位置映射移动
- 宽度变化时真实换行，避免每帧把整段文字挤压
- 根据空间改列数与间距，保留阅读和键盘顺序

验收：不同长度内容不会重叠，视觉顺序和DOM顺序不冲突。

### 7. Reverse Collapse｜逆向收起

适用：把展开任务区恢复为有效入口。

- 以当前可见几何作为起点，不重播完整正向动画
- 先处理内部焦点和退出内容，再缩回外壳
- 源入口已消失则短退场，不使用过期坐标

验收：半途反悔和连续开合无跳变，收起后焦点有归属。

## 动效与集成规则

- 拖动、滚动等连续输入直接控制当前进度；不要附加长时 CSS transition 让画面追赶手指。释放后的收尾才使用合适的缓入缓出或阻尼弹簧。固定动画时长根据距离、内容和设备调整，不把慢速当作顺滑。
- 点击反馈及时发生；短过渡可从约 160–280ms 起调，较大展开可从约 240–420ms 起调，这些仅是初值。稳定阅读时停住，不让整个页面持续放大或漂移。
- 一个属性同一时刻由一个控制源更新。重复输入从当前可见状态接续或明确合并，旧回调不能覆盖新状态。数据更新与装饰动画解耦。
- 测量真实内容尺寸，不用非等比缩放压扁文字、图片和控件。窄屏应改布局、换行或分页，长文本与空数据也能显示。
- 使用正确的原生元素或组件语义，保留键盘、触摸和辅助技术入口。减少动态效果时直接切换或使用短淡入，核心功能仍完整。
- 优先局部更新，避免每帧交错读取和写入整页布局；卸载时清理事件、定时器、动画循环与过期异步任务。

## 实际验收与交付

检查所选模式的正常操作、逆向或撤回、连续触发、取消、边界和内容变化。实际打开目标页面检查桌面与手机布局、键盘操作和减少动态效果；有构建或相关行为测试时执行适当检查。录屏或抽帧可用于发现遮挡、压缩和过渡跳变，但静态截图不能证明交互正常。

交付说明选型理由、修改位置、输入与结束规则、可调参数，以及实际执行的检查。区分结构检查、构建通过、浏览器操作和设备测试；没运行的验证明确标记，不承诺未经测量的性能。
