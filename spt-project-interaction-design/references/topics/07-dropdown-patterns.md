# 8 种下拉选单组件

> 按需参考 · 主题 07《8种下拉选单》。仅使用总入口选定的模式，不把本页全部效果加入项目。任务范围、输出形式与语言以用户当前请求和总入口为准。

## 模式选择与实现约束

### 1. Single Select｜下拉单选

适用：从固定集合选择一个值。

- 优先现有可访问选择组件或原生select
- 值、显示标签和占位区分，支持清除及禁用规则
- 可搜索键入定位或方向键选择，关闭后恢复焦点

验收：默认值、无选项、长标签与键盘操作正确。

### 2. Option Groups｜选项分组

适用：较多同类选项按类别组织。

- 组名为结构标签不可误选
- 保持全局选项ID唯一，筛选后仍显示正确分组
- 空分组按约定隐藏或标为空，不插入假选项

验收：跨组选择、同名不同ID和禁用项正常。

### 3. Typeahead｜搜索选择

适用：候选很多或需要远程查询。

- 输入文本与已提交选项分离，按需求确定允许自由输入
- 处理中文输入法合成；远程请求防抖并取消或忽略过期结果
- 加载、无结果、失败及清空都有状态，键盘高亮有可访问关联

验收：快速输入不被旧结果覆盖，中文输入不中断。

### 4. Split Action｜分裂按钮

适用：主要动作旁提供其他命令。

- 主按钮直接执行主动作，箭头只打开菜单
- 两个触发区名称和焦点分开
- 选择备用动作是否改变默认项由业务明确

验收：主按钮不误开菜单，箭头不误提交，无双触发。

### 5. Date Range｜日期范围

适用：选择起止日期。

- 区分选择中预览和最终提交，明确反向选择规则
- 以项目时区和日期边界处理，禁选日期与最短最长范围一致
- 支持键盘或直接输入，校验非法格式与跨月跨年

验收：闰日、跨年、时区边界与取消不会生成错日期。

### 6. Cascade｜级联选择

适用：省市区或多层级分类。

- 父项变化清理无效子项，保留稳定ID路径
- 懒加载有独立加载错误状态，过期请求不覆盖新父项
- 确定可否选父项；手机用分步面板避免多列挤压

验收：换父项、返回上层、空叶子与加载失败可恢复。

### 7. Tag Picker｜多标签选择

适用：选择多个筛选值或成员。

- 集合按稳定ID去重，输入和已选标签区分
- 删除标签有可读入口，处理上限、全选和清空规则
- 大量标签折叠摘要但提供查看编辑入口

验收：重复选择不重复添加，键盘删除与长标签不破坏布局。

### 8. Mega Menu｜超级菜单

适用：复杂站点的多组导航目的地。

- 真实链接按信息架构分组，不伪造营销卡片填空
- 悬停和点击策略稳定，指针跨到面板不立即关闭
- 手机改折叠菜单，键盘可展开、遍历和退出

验收：移动路径不闪退，所有链接可达，小屏不横向溢出。

## 动效与集成规则

- 拖动、滚动等连续输入直接控制当前进度；不要附加长时 CSS transition 让画面追赶手指。释放后的收尾才使用合适的缓入缓出或阻尼弹簧。固定动画时长根据距离、内容和设备调整，不把慢速当作顺滑。
- 点击反馈及时发生；短过渡可从约 160–280ms 起调，较大展开可从约 240–420ms 起调，这些仅是初值。稳定阅读时停住，不让整个页面持续放大或漂移。
- 一个属性同一时刻由一个控制源更新。重复输入从当前可见状态接续或明确合并，旧回调不能覆盖新状态。数据更新与装饰动画解耦。
- 测量真实内容尺寸，不用非等比缩放压扁文字、图片和控件。窄屏应改布局、换行或分页，长文本与空数据也能显示。
- 使用正确的原生元素或组件语义，保留键盘、触摸和辅助技术入口。减少动态效果时直接切换或使用短淡入，核心功能仍完整。
- 优先局部更新，避免每帧交错读取和写入整页布局；卸载时清理事件、定时器、动画循环与过期异步任务。

## 实际验收与交付

检查所选模式的正常操作、逆向或撤回、连续触发、取消、边界和内容变化。实际打开目标页面检查桌面与手机布局、键盘操作和减少动态效果；有构建或相关行为测试时执行适当检查。录屏或抽帧可用于发现遮挡、压缩和过渡跳变，但静态截图不能证明交互正常。

交付说明选型理由、修改位置、输入与结束规则、可调参数，以及实际执行的检查。区分结构检查、构建通过、浏览器操作和设备测试；没运行的验证明确标记，不承诺未经测量的性能。
