# 7 种标题文字动效

> 按需参考 · 主题 13《7种标题文字动效》。仅使用总入口选定的模式，不把本页全部效果加入项目。任务范围、输出形式与语言以用户当前请求和总入口为准。

## 模式选择与实现约束

### 1. Split Text Entrance｜拆分入场

适用：首屏或章节标题按字词错峰出现。

- 按语言和字素簇拆分，中文、emoji和组合字符不能被切坏
- 保留完整可访问标题，视觉副本对辅助技术隐藏
- 错峰总时长受控，按实际换行组织，不逐字排成固定单行

验收：窄屏换行、字体加载、长标题均不溢出或重复朗读。

### 2. Blur Reveal｜模糊揭示

适用：柔和出现的短标题。

- 小幅模糊伴随透明度或轻位移，最后清晰归零
- 限制模糊范围与区域，避免整页高成本滤镜
- 减少动态效果直接显示，离屏不持续运行

验收：最终文字清楚，无模糊残留或裁切阴影。

### 3. Text Scramble｜乱码解码

适用：科技感短句或强调词。

- 目标文案固定，临时字符只作为视觉过程
- 预留最终布局宽度，随机更新频率与时长受控
- 不乱码化关键数值、错误说明或按钮可访问名称

验收：完成严格等于目标文本，连触发和中途离开能稳定结束。

### 4. Typewriter｜打字机

适用：逐步出现的简短叙述或命令示例。

- 按字素簇递增，标点可微调节奏但总等待有限
- 保留段落最终空间或明确允许自然增长
- 提供跳过或完整文案，光标装饰不重复播报字符

验收：中文和emoji完整，长内容可快速阅读，重复触发不叠计时器。

### 5. Gradient Shimmer｜渐变扫光

适用：短品牌标题的一次强调。

- 渐变裁切到文字内部，基础文字始终有足够对比
- 控制光带宽度与次数，不永久高频闪烁
- 不支持裁切时显示普通文字，减少动态效果为静态色

验收：深浅背景都可读，结束后文案不变透明。

### 6. Text Mask Reveal｜文字遮罩揭示

适用：标题从边界或逐行进入。

- 每行设置揭示边界，文字保持真实字号与比例
- 按字体实际行盒预留上下延伸，避免切掉字形
- 响应式换行或字体加载后重建行分组，保持语义标题

验收：多行中文和英文下伸部不被裁切，窗口变化无错行。

### 7. Stroke Writing｜描边书写

适用：已有路径的Logo或短艺术字。

- 有SVG路径时按实际路径长度映射描边，结束可填充
- 轮廓描边不等于真实笔顺；无笔画路径不能声称模拟书写
- 普通正文保留文本与字体，不转大量路径损害阅读

验收：路径闭合和终点正常，替代文本可读，素材失败有文字版。

## 动效与集成规则

- 拖动、滚动等连续输入直接控制当前进度；不要附加长时 CSS transition 让画面追赶手指。释放后的收尾才使用合适的缓入缓出或阻尼弹簧。固定动画时长根据距离、内容和设备调整，不把慢速当作顺滑。
- 点击反馈及时发生；短过渡可从约 160–280ms 起调，较大展开可从约 240–420ms 起调，这些仅是初值。稳定阅读时停住，不让整个页面持续放大或漂移。
- 一个属性同一时刻由一个控制源更新。重复输入从当前可见状态接续或明确合并，旧回调不能覆盖新状态。数据更新与装饰动画解耦。
- 测量真实内容尺寸，不用非等比缩放压扁文字、图片和控件。窄屏应改布局、换行或分页，长文本与空数据也能显示。
- 使用正确的原生元素或组件语义，保留键盘、触摸和辅助技术入口。减少动态效果时直接切换或使用短淡入，核心功能仍完整。
- 优先局部更新，避免每帧交错读取和写入整页布局；卸载时清理事件、定时器、动画循环与过期异步任务。

## 实际验收与交付

检查所选模式的正常操作、逆向或撤回、连续触发、取消、边界和内容变化。实际打开目标页面检查桌面与手机布局、键盘操作和减少动态效果；有构建或相关行为测试时执行适当检查。录屏或抽帧可用于发现遮挡、压缩和过渡跳变，但静态截图不能证明交互正常。

交付说明选型理由、修改位置、输入与结束规则、可调参数，以及实际执行的检查。区分结构检查、构建通过、浏览器操作和设备测试；没运行的验证明确标记，不承诺未经测量的性能。
