# 6 种拖拽交互

> 按需参考 · 主题 05《6种拖拽交互》。仅使用总入口选定的模式，不把本页全部效果加入项目。任务范围、输出形式与语言以用户当前请求和总入口为准。

## 模式选择与实现约束

### 1. Drag and Drop｜拖放

适用：把对象放到有效目标。

- 保留按下点与对象的偏移，坐标转换包含滚动和缩放
- 预览只提示合法落点，释放时验证目标仍存在且可接受
- 取消或无效释放恢复；提供移动到目标的非拖动入口

验收：拖出容器仍能结束，非法目标不提交，重复放置稳定。

### 2. Sortable List｜拖拽排序

适用：改变列表或网格顺序。

- 使用稳定ID和真实项目边界计算插入位，不能仅用固定行高
- 预留落点空槽，邻项让位，长列表边缘可受控自动滚动
- 预览顺序与提交分开，取消恢复原序，键盘可上移下移

验收：不同行高、跨多项、回拖、取消和保存失败都不丢项。

### 3. Slider Drag｜滑杆拖动

适用：选择连续或离散数值。

- 按轨道有效长度映射数值并夹取范围，步长舍入一致
- 滑块跟手，显示值与业务值更新策略明确
- 方向键、Home与End可用；双滑块明确能否交叉

验收：边界、负数、不同步长及尺寸变化数值准确。

### 4. Resize Drag｜尺寸调整

适用：改变面板、列或对象尺寸。

- 固定对侧锚点，约束最小最大尺寸，必要时保持比例
- 容器边界与邻项最小宽度一并约束
- 拖动时显示当前尺寸，取消恢复；有键盘或数值替代

验收：各方向手柄正确，拖过极限不翻转，文字不被缩放。

### 5. Marquee Selection｜框选与多选

适用：在平面区域批量选择对象。

- 四方向拖动归一化矩形，明确相交或完整包含的判定
- 空白处框选，节点处拖动；修饰键实现追加或切换
- 坐标与画布缩放一致，取消保留先前集合

验收：反向框选、缩放后框选和追加选择均准确。

### 6. Drag to Upload｜拖拽上传

适用：向区域输入本地文件。

- 同时提供原生文件选择入口，校验类型、大小与数量
- 嵌套元素进入离开不闪烁，区分文件拖入与页面内部拖动
- 预览、上传进度、失败重试与取消由真实任务状态驱动

验收：非法文件、批量文件、部分失败和重复操作有清楚结果。

## 动效与集成规则

- 拖动、滚动等连续输入直接控制当前进度；不要附加长时 CSS transition 让画面追赶手指。释放后的收尾才使用合适的缓入缓出或阻尼弹簧。固定动画时长根据距离、内容和设备调整，不把慢速当作顺滑。
- 点击反馈及时发生；短过渡可从约 160–280ms 起调，较大展开可从约 240–420ms 起调，这些仅是初值。稳定阅读时停住，不让整个页面持续放大或漂移。
- 一个属性同一时刻由一个控制源更新。重复输入从当前可见状态接续或明确合并，旧回调不能覆盖新状态。数据更新与装饰动画解耦。
- 测量真实内容尺寸，不用非等比缩放压扁文字、图片和控件。窄屏应改布局、换行或分页，长文本与空数据也能显示。
- 使用正确的原生元素或组件语义，保留键盘、触摸和辅助技术入口。减少动态效果时直接切换或使用短淡入，核心功能仍完整。
- 优先局部更新，避免每帧交错读取和写入整页布局；卸载时清理事件、定时器、动画循环与过期异步任务。

## 实际验收与交付

检查所选模式的正常操作、逆向或撤回、连续触发、取消、边界和内容变化。实际打开目标页面检查桌面与手机布局、键盘操作和减少动态效果；有构建或相关行为测试时执行适当检查。录屏或抽帧可用于发现遮挡、压缩和过渡跳变，但静态截图不能证明交互正常。

交付说明选型理由、修改位置、输入与结束规则、可调参数，以及实际执行的检查。区分结构检查、构建通过、浏览器操作和设备测试；没运行的验证明确标记，不承诺未经测量的性能。
