# 6 种浮层组件

> 按需参考 · 主题 02《6种弹层组件》。仅使用总入口选定的模式，不把本页全部效果加入项目。任务范围、输出形式与语言以用户当前请求和总入口为准。

## 模式选择与实现约束

### 1. Tooltip｜提示

适用：图标含义或简短补充信息。

- 悬停和键盘聚焦均可触发；不承载表单和可点击长内容
- 关联触发器描述，移出或 Escape 关闭，触摸不依赖悬停
- 定位避开边界且不覆盖关键目标

验收：键盘可读，视口边缘不裁切，不出现无法关闭的提示。

### 2. Popover｜轻量浮面

适用：依附按钮的详情、小表单或局部操作。

- 锚定真实触发器，滚动和尺寸变化时重新定位
- 按内容语义决定焦点进入和退出；非模态不强行锁全页
- 外部点击与内部点击区分，关闭后恢复合理焦点

验收：浮层内部操作不误关闭，锚点移出或卸载时状态稳定。

### 3. Dropdown｜操作菜单

适用：从按钮选择一项命令。

- 区分命令菜单与数据选择，语义不能混用
- 支持方向键、首尾项、Escape与禁用项，执行一次
- 根据剩余空间翻转或限高滚动，不压缩菜单文字

验收：键盘能遍历有效项，触发器和菜单之间不闪退。

### 4. Drawer｜侧边抽屉

适用：保留上下文查看详情或编辑。

- 明确是否模态；模态需管理焦点、背景交互和滚动
- 宽度按设备适配，头部与操作区可固定，正文独立滚动
- 未保存内容关闭遵循现有业务规则，不默默丢弃

验收：长表单、窄屏、关闭后焦点和页面滚动恢复正确。

### 5. Bottom Sheet｜底部面板

适用：移动端局部任务或多档高度内容。

- 定义收起、半屏、全屏等实际需要的停靠点
- 拖动手柄与内容滚动协商，内容未到顶部不随意拉走面板
- 软键盘和安全区出现时保留输入与操作入口

验收：拖动取消、快速甩动、长内容滚动和键盘弹出不冲突。

### 6. Modal｜模态对话框

适用：必须聚焦处理的确认或独立任务。

- 设置可访问标题、初始焦点、焦点约束和背景不可交互
- 按任务决定遮罩与Escape是否关闭，危险动作不默认获得确认焦点
- 关闭后恢复触发位置，嵌套对话框只让最上层处理关闭

验收：Tab不漏到背景，取消不执行业务，多层关闭无残留遮罩。

## 动效与集成规则

- 拖动、滚动等连续输入直接控制当前进度；不要附加长时 CSS transition 让画面追赶手指。释放后的收尾才使用合适的缓入缓出或阻尼弹簧。固定动画时长根据距离、内容和设备调整，不把慢速当作顺滑。
- 点击反馈及时发生；短过渡可从约 160–280ms 起调，较大展开可从约 240–420ms 起调，这些仅是初值。稳定阅读时停住，不让整个页面持续放大或漂移。
- 一个属性同一时刻由一个控制源更新。重复输入从当前可见状态接续或明确合并，旧回调不能覆盖新状态。数据更新与装饰动画解耦。
- 测量真实内容尺寸，不用非等比缩放压扁文字、图片和控件。窄屏应改布局、换行或分页，长文本与空数据也能显示。
- 使用正确的原生元素或组件语义，保留键盘、触摸和辅助技术入口。减少动态效果时直接切换或使用短淡入，核心功能仍完整。
- 优先局部更新，避免每帧交错读取和写入整页布局；卸载时清理事件、定时器、动画循环与过期异步任务。

## 实际验收与交付

检查所选模式的正常操作、逆向或撤回、连续触发、取消、边界和内容变化。实际打开目标页面检查桌面与手机布局、键盘操作和减少动态效果；有构建或相关行为测试时执行适当检查。录屏或抽帧可用于发现遮挡、压缩和过渡跳变，但静态截图不能证明交互正常。

交付说明选型理由、修改位置、输入与结束规则、可调参数，以及实际执行的检查。区分结构检查、构建通过、浏览器操作和设备测试；没运行的验证明确标记，不承诺未经测量的性能。
