# 7 种加载动效

> 按需参考 · 主题 01《7种加载动效》。仅使用总入口选定的模式，不把本页全部效果加入项目。任务范围、输出形式与语言以用户当前请求和总入口为准。

## 模式选择与实现约束

### 1. Page Loader｜整页加载

适用：首次启动确实尚不能提供可用内容。

- 仅阻挡依赖初始化的内容；可用页面优先渐进呈现
- 成功、超时、失败、重试均有明确状态；避免无限转圈
- 重复初始化共享任务状态，完成后释放遮罩和焦点

验收：慢网络、失败重试、返回页面均能离开加载态。

### 2. Skeleton｜骨架屏

适用：列表、卡片或详情布局可提前确定。

- 占位对应真实标题、图片和行高，保留空间减少布局跳动
- 内容分批完成可局部替换，不等全部请求结束
- 骨架对辅助技术隐藏，在真实容器表达忙碌状态

验收：长短数据切换不挤压，空列表与失败不留下假内容。

### 3. Shimmer｜扫光

适用：需要让骨架的等待状态更易辨认。

- 用裁切的柔和渐变扫过占位，不逐个节点做高强度闪烁
- 同一块区域统一方向和节奏，限制同时运动区域
- 内容准备好立即停止；减少动态效果保留静态骨架

验收：扫光不越出圆角、不影响正文，对比不过强。

### 4. Spinner｜旋转加载

适用：持续时间未知的短局部任务。

- 放在触发区域附近，提供任务文本，旋转可以连续匀速
- 短请求可延迟显示避免闪一下，但业务完成不能人为延迟
- 失败转为错误与重试；不可把转速当作进度

验收：快速请求无明显闪烁，长请求可理解且有退出路径。

### 5. Progress Bar｜线形进度

适用：上传、下载或可测量步骤存在可靠进度。

- 由已完成量与总量计算，未知总量使用不定进度
- 不要计时假跑到 99%；传输完成后服务端处理另标状态
- 标明任务和进度语义，错误或取消停止推进

验收：真实完成前不显示成功，零总量和恢复任务处理正确。

### 6. Circular Progress｜环形进度

适用：紧凑区域展示可确定的任务进度。

- 按圆周长映射描边偏移，百分比与真实数据同源
- 未知进度应换不定状态，不伪造环形百分比
- 数字不要逐帧播报，尺寸变化后圆环与文字仍居中

验收：0、50、100%几何对应，数字不溢出且错误可辨。

### 7. Button Loading｜按钮加载

适用：提交、保存等单个动作等待响应。

- 按钮宽度保持稳定，文案说明进行中的任务
- 请求进行时防止重复提交；失败恢复操作并保留输入
- 处理超时、取消和组件卸载；成功状态来自实际结果

验收：连点只提交一次，失败可重试，键盘激活同样有效。

## 动效与集成规则

- 拖动、滚动等连续输入直接控制当前进度；不要附加长时 CSS transition 让画面追赶手指。释放后的收尾才使用合适的缓入缓出或阻尼弹簧。固定动画时长根据距离、内容和设备调整，不把慢速当作顺滑。
- 点击反馈及时发生；短过渡可从约 160–280ms 起调，较大展开可从约 240–420ms 起调，这些仅是初值。稳定阅读时停住，不让整个页面持续放大或漂移。
- 一个属性同一时刻由一个控制源更新。重复输入从当前可见状态接续或明确合并，旧回调不能覆盖新状态。数据更新与装饰动画解耦。
- 测量真实内容尺寸，不用非等比缩放压扁文字、图片和控件。窄屏应改布局、换行或分页，长文本与空数据也能显示。
- 使用正确的原生元素或组件语义，保留键盘、触摸和辅助技术入口。减少动态效果时直接切换或使用短淡入，核心功能仍完整。
- 优先局部更新，避免每帧交错读取和写入整页布局；卸载时清理事件、定时器、动画循环与过期异步任务。

## 实际验收与交付

检查所选模式的正常操作、逆向或撤回、连续触发、取消、边界和内容变化。实际打开目标页面检查桌面与手机布局、键盘操作和减少动态效果；有构建或相关行为测试时执行适当检查。录屏或抽帧可用于发现遮挡、压缩和过渡跳变，但静态截图不能证明交互正常。

交付说明选型理由、修改位置、输入与结束规则、可调参数，以及实际执行的检查。区分结构检查、构建通过、浏览器操作和设备测试；没运行的验证明确标记，不承诺未经测量的性能。
