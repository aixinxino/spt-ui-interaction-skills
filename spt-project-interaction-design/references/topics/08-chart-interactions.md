# 7 种图表交互

> 按需参考 · 主题 08《7种图表交互》。仅使用总入口选定的模式，不把本页全部效果加入项目。任务范围、输出形式与语言以用户当前请求和总入口为准。

## 模式选择与实现约束

### 1. Brush Selection｜刷选

适用：选择连续区间或二维数据区域。

- 从绘图区像素反算数据范围，明确作用轴与选择规则
- 预览与提交分离，提供清除和范围文本
- 缩放或筛选后重新校验选区，修饰键策略明确

验收：反向拖动、空区间、时间轴及缩放后范围准确。

### 2. Crosshair｜十字准线

适用：对齐读取同一位置上的多系列值。

- 指针换算到绘图区坐标，明确最近类目或连续插值
- 多图联动用同一数据域，不用不同图的像素硬对齐
- 标签避开边缘，指针离开或无数据时按规则隐藏

验收：轴边界、缺失值和多系列不同采样点不会错配。

### 3. Data Point Highlight｜数据点高亮

适用：强调当前观察或选中的数据。

- hover、键盘焦点和已选点状态区分
- 扩大命中区但不改变数据点真实坐标
- 高亮样式不只靠颜色，密集点按清楚的邻近规则选取

验收：重叠点和小目标可操作，退出不留下错误选中。

### 4. Tooltip｜数据提示

适用：显示数据值、单位和上下文。

- 取真实数据而非从画面反推，格式与轴口径一致
- 定位限制在可见区，避免遮挡当前点
- 简单提示不放交互；需要按钮时改为可聚焦详情面板

验收：负值、空值、长名称、单位与键盘读取正确。

### 5. Legend Filter｜图例筛选

适用：显示或隐藏系列以便比较。

- 图例状态与可见系列同源，支持键盘切换
- 明确隐藏后是否重算轴域并提示尺度变化
- 规定全部隐藏行为，保留恢复入口

验收：反复筛选可恢复，百分比或堆叠数据口径不被误改。

### 6. Zoom｜图表缩放

适用：观察局部数据而保留上下文。

- 缩放数据域并重绘轴与图形，不放大一张截图
- 夹取最小最大范围，指针锚定或中心锚定规则一致
- 提供重置和按钮入口，与页面滚动、刷选区分输入

验收：反复缩放无域漂移，坐标刻度与提示同步。

### 7. Drill Down｜数据下钻

适用：从汇总查看其组成明细。

- 保留筛选条件与父级路径，查询真实子级数据
- 加载失败留在可恢复上下文，不展示上次对象明细
- 提供返回上层，回退恢复尺度和必要的选择状态

验收：多层返回、无明细、快速点不同对象不串数据。

## 动效与集成规则

- 拖动、滚动等连续输入直接控制当前进度；不要附加长时 CSS transition 让画面追赶手指。释放后的收尾才使用合适的缓入缓出或阻尼弹簧。固定动画时长根据距离、内容和设备调整，不把慢速当作顺滑。
- 点击反馈及时发生；短过渡可从约 160–280ms 起调，较大展开可从约 240–420ms 起调，这些仅是初值。稳定阅读时停住，不让整个页面持续放大或漂移。
- 一个属性同一时刻由一个控制源更新。重复输入从当前可见状态接续或明确合并，旧回调不能覆盖新状态。数据更新与装饰动画解耦。
- 测量真实内容尺寸，不用非等比缩放压扁文字、图片和控件。窄屏应改布局、换行或分页，长文本与空数据也能显示。
- 使用正确的原生元素或组件语义，保留键盘、触摸和辅助技术入口。减少动态效果时直接切换或使用短淡入，核心功能仍完整。
- 优先局部更新，避免每帧交错读取和写入整页布局；卸载时清理事件、定时器、动画循环与过期异步任务。

## 实际验收与交付

检查所选模式的正常操作、逆向或撤回、连续触发、取消、边界和内容变化。实际打开目标页面检查桌面与手机布局、键盘操作和减少动态效果；有构建或相关行为测试时执行适当检查。录屏或抽帧可用于发现遮挡、压缩和过渡跳变，但静态截图不能证明交互正常。

交付说明选型理由、修改位置、输入与结束规则、可调参数，以及实际执行的检查。区分结构检查、构建通过、浏览器操作和设备测试；没运行的验证明确标记，不承诺未经测量的性能。
