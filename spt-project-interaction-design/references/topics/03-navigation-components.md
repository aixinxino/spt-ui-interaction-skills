# 7 种导航组件

> 按需参考 · 主题 03《7种导航组件》。仅使用总入口选定的模式，不把本页全部效果加入项目。任务范围、输出形式与语言以用户当前请求和总入口为准。

## 模式选择与实现约束

### 1. Tabs｜标签页

适用：同一上下文的并列内容面板。

- 按钮与面板一一关联，方向键移动焦点
- 切换昂贵内容时可采用手动激活；保持加载状态可理解
- 快速切换取消旧请求或忽略旧结果，按需求保留面板状态

验收：焦点与选中状态清楚，异步结果不会串页。

### 2. Segmented Control｜分段控制器

适用：少量互斥视图、范围或模式。

- 先判断是单选值还是面板导航，分别采用对应语义
- 选项宽度容纳文字，选中背景跟随真实边界
- 切换保持相关内容上下文，不强行改变路由

验收：长标签、小屏和键盘选择均准确，不仅靠颜色识别。

### 3. Breadcrumb｜面包屑

适用：展示当前位置在层级中的路径。

- 路径来自实际信息层级，当前页标识而非虚假链接
- 长路径可折叠中间层但保留可访问入口
- 不要把浏览历史误作层级路径

验收：深链接打开时路径正确，上级链接真实可用。

### 4. Sidebar Navigation｜侧栏导航

适用：较多页面与分组层级。

- 当前项由路由派生，展开组与当前页关系明确
- 折叠后图标仍有名称，手机可转抽屉并处理焦点
- 长导航可滚动，不让底部重要入口被挤走

验收：刷新和返回高亮正确，窄屏菜单能打开关闭。

### 5. Bottom Navigation｜底部导航

适用：移动端少量主要目的地。

- 使用导航链接语义和可读标签，不机械当Tab
- 保留安全区，正文留出底部空间，键盘弹出不遮输入
- 二级操作不挤入主目的地，切换保留合理滚动历史

验收：页面底部内容可见，路由返回、长标签和触摸均正常。

### 6. Stepper｜步骤导航

适用：有先后顺序的表单或办理流程。

- 区分完成、当前、未开始、错误；允许跳转范围由业务决定
- 校验失败停在当前步骤并定位错误，数据跨步保留
- 视觉进度不虚构完成，返回修改后重新计算依赖

验收：不能越过必要校验，后退不丢输入，最终只提交一次。

### 7. Pagination｜分页

适用：有明确页边界的数据集合。

- 页码与查询参数及数据源一致，切页处理加载与失败
- 筛选改变时重置或合法夹取页码，总数变化处理末页
- 保持合理焦点和阅读位置，不让旧请求覆盖新页

验收：首页末页、无数据、快速翻页和浏览器返回正确。

## 动效与集成规则

- 拖动、滚动等连续输入直接控制当前进度；不要附加长时 CSS transition 让画面追赶手指。释放后的收尾才使用合适的缓入缓出或阻尼弹簧。固定动画时长根据距离、内容和设备调整，不把慢速当作顺滑。
- 点击反馈及时发生；短过渡可从约 160–280ms 起调，较大展开可从约 240–420ms 起调，这些仅是初值。稳定阅读时停住，不让整个页面持续放大或漂移。
- 一个属性同一时刻由一个控制源更新。重复输入从当前可见状态接续或明确合并，旧回调不能覆盖新状态。数据更新与装饰动画解耦。
- 测量真实内容尺寸，不用非等比缩放压扁文字、图片和控件。窄屏应改布局、换行或分页，长文本与空数据也能显示。
- 使用正确的原生元素或组件语义，保留键盘、触摸和辅助技术入口。减少动态效果时直接切换或使用短淡入，核心功能仍完整。
- 优先局部更新，避免每帧交错读取和写入整页布局；卸载时清理事件、定时器、动画循环与过期异步任务。

## 实际验收与交付

检查所选模式的正常操作、逆向或撤回、连续触发、取消、边界和内容变化。实际打开目标页面检查桌面与手机布局、键盘操作和减少动态效果；有构建或相关行为测试时执行适当检查。录屏或抽帧可用于发现遮挡、压缩和过渡跳变，但静态截图不能证明交互正常。

交付说明选型理由、修改位置、输入与结束规则、可调参数，以及实际执行的检查。区分结构检查、构建通过、浏览器操作和设备测试；没运行的验证明确标记，不承诺未经测量的性能。
