# 6 种后台菜单交互

> 按需参考 · 主题 25《6种后台菜单交互》。仅使用总入口选定的模式，不把本页全部效果加入项目。任务范围、输出形式与语言以用户当前请求和总入口为准。

先读取路由、栏目层级、权限、当前项计算、布局和组件库。根据入口数量、层级和使用频率选择合适组合；不把六种导航全部塞进同一后台。用户只要方案时说明位置和理由，不直接改项目。

## 1. Moving Active Background｜滑动高亮块

适合侧栏或标签中的当前位置提示。当前项来自真实路由或选中状态；底色在菜单项之间连续移动，文字与图标保持稳定。

测量目标的位置与尺寸，按当前设计采用整行或内容宽度，不机械要求所有侧栏都包文字。快速切换从当前可见几何接续，旧动画回调不能覆盖新路由。折叠、滚动、字体加载或窗口变化后重新测量。

指令：让同一块选中背景跟随实际当前项移动和变宽，标签本身不晃动，连续切换从当前位置接续，并处理刷新和浏览器返回。

验收：深链接打开、返回、不同宽度标签及连续切换都指向正确页面，无双重高亮残留。

## 2. Inline Submenu｜就地子菜单

适合项目、文件等父子栏目。父项按钮负责展开，真实页面链接负责导航，不让一个点击意外执行两个动作。

子项在父项下方出现，容器高度与后续栏目位置共同变化，箭头对应展开状态。单组还是多组展开沿用业务约定；仅在目标是手风琴导航时限制为一组。按真实内容测高，不能截断长名称。

指令：在父栏目下平滑展开子项，邻项顺势下移，文字可轻微错峰；收起逆向恢复，处理键盘、长内容与连续开关。

验收：关闭后隐藏链接不可被 Tab 访问；当前子页所在组有明确位置提示；连续开合无高度跳变。

## 3. Top Dropdown Panel｜顶部下落面板

适合一级栏目较少、子入口较多的后台。复用一个面板容器，切换一级栏目时更新内部内容与必要尺寸，避免整层反复闪白。

点击和键盘都能打开，不只依赖悬停。鼠标从触发项走向面板时不能因细小空隙马上关闭；离开整个交互区域、明确外部点击或 Escape 时按项目规则收起。真实链接、禁用状态和分组标题清楚。

指令：顶部栏目展开分组导航面板，共享外框，切换内容平滑且不中断访问；补齐点击、键盘、边界定位和稳定关闭逻辑。

验收：跨越触发器到面板不闪退；所有真实子页可达；手机使用合适的展开结构，不硬挤桌面多列。

## 4. Floating Dock｜底部悬浮停靠栏

适合少量高频目的地。按指针到图标基准中心的距离连续计算大小，相邻项协同让位，离开后恢复；测量不使用正在被放大的边界，避免自激抖动。

预留放大与名称提示空间，当前页标识独立于悬停反馈。正文底部保留停靠栏实际占用高度，安全区域及键盘弹出时不遮挡重要按钮。触屏保留稳定的点击尺寸，不等待不存在的悬停。

指令：做底部悬浮导航，距离驱动图标放大和邻项让位，名称清楚、当前项明确，手机与键盘都有稳定入口。

验收：慢慢横移连续，静止不抖，最后一段正文可读，所有入口仍是正确链接。

## 5. Command Palette｜命令面板

适合入口很多或需要快速搜索的后台。整理真实入口的名称、关键词、行为和可用条件，区分打开页面与执行命令；搜索和键盘高亮都不能提前执行动作。

提供可点击的打开入口，快捷键只作补充。方向键移动高亮，回车确认，Escape 关闭；中文输入法组字时不抢回车。空结果和权限不足有明确说明。命令需要参数或确认时先补齐，不因选中第一步就提前执行危险操作。

如果实现为模态，管理背景与焦点；关闭回到原入口或合理位置，导航成功后焦点到目标页面，不强行回到已卸载的按钮。

指令：加入可点击打开的命令面板，搜索真实页面和动作，支持键盘选择与中文输入法；关闭恢复焦点，执行前检查可用条件。

验收：中文输入确认不误执行；快速搜索不出现旧结果覆盖；禁用项不可执行；关闭后页面可继续操作。

## 6. Status Dots and Badges｜状态点与计数徽标

适合未读消息和待处理事项。徽标绑定真实状态，数字、可访问描述和列表统计保持同源；仅后台确认或项目明确已读规则满足时清除，不在鼠标经过时清零。

数字更新可局部滚动，预留足够空间，不推动导航项来回挪。零值隐藏、数量上限显示等遵守产品规则；语义名称保留实际含义。请求失败不乐观清空，频繁更新可合并视觉动画但不能丢计数。

指令：让状态点与数量跟真实数据更新，数字局部过渡，确认已读后退出；入口位置保持稳定，失败和快速更新不丢状态。

验收：新增、减少、清零、失败和多来源刷新均正确；不只靠颜色表达未读；不存在假数字定时增长。

## 集成与交付

保留已有组件的路由、焦点、键盘和权限能力，不为动效换掉整套成熟导航。自动过渡短而有缓入缓出，到位停稳；降低动态效果时直接呈现正确状态。

实际检查刷新、返回、窄屏、长菜单、快速切换、键盘和数据失败，交付改动文件、选型原因、验证结果与未测试项。无需发布、安装 Skill 或制作视频。
